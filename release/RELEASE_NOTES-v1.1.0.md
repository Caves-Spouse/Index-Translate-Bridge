# v1.1.0 — 语音翻译

给 Index-Translate 本地代理桥加了 App 内语音翻译：不用切到浏览器，按住说话就能出中文译文。

## 新增

- **语音翻译面板**（主界面下方）：「按住说话」→ 松手 → 系统 `SpeechRecognizer` 识别 → Index-Translate 翻成简体中文
- 「原文 / 译文」双栏同屏，识别过程中的文字实时显示在原文栏
- **一键复制译文**到剪贴板
- 识别语言可选 **英语 / 日语 / 韩语 / 跟随系统**（目标语言固定简体中文）
- 翻译链路复用本机代理（`127.0.0.1:端口`），**代理没开也能用**（直连上游）；建连 10s / 读 60s 超时，失败给出具体原因
- 沿用 `chat_template_kwargs.enable_thinking=false`，思考文本不会混进译文

## 权限与隐私

- 仅新增 `android.permission.RECORD_AUDIO`，首次按住时才申请；拒绝后只提示、不崩溃
- 麦克风仅在按住期间录音，录音交给系统自带语音识别服务转文字，**本 App 不保存录音**
- 仍只监听 `127.0.0.1`，不对外暴露；上游地址不变

## 兼容性

- 体积 32KB → 37KB，仍**零第三方依赖**（纯 Java + JDK 标准库），无需 Gradle
- 代理转发 / SSE 直通 / gzip / 端口探测 / 保活逻辑**完全未改**，沉浸式翻译配置照旧
- Android 7.0+（minSdk 24，targetSdk 34）；同签名可直接覆盖升级

## 已知限制

- 语音识别由系统语音服务完成：部分机型需联网，需在系统里启用语音输入；不可用时按钮会置灰
- 目标语言固定简体中文，本版不做目标语言选择器、不做 TTS 朗读、不保存历史记录
