Index-Translate 本地代理桥 · 使用说明
================================================

这是一个"翻译代理"小工具。它把沉浸式翻译的请求，转发到 bilibili 官方的
Index-Translate 翻译模型（默认 9B），解决浏览器扩展直连会报错的问题。

体积 37KB，不需要 Termux、不需要 root、不需要任何账号。


一、安装
------------------------------------------------
1. 把 index-translate-bridge-x.y.z.apk 传到手机，点击安装。
2. 会提示"未知来源 / 未经 Play Protect 扫描"——这是所有非商店 APK 的正常提示，
   选「仍要安装」即可。
3. 需要 Android 7.0 及以上。
4. 如果之前装过旧版：
   - 同一签名 → 直接覆盖安装，配置保留；
   - 换了签名 → 必须卸载后重装（会丢失设置）。


二、启动（就是点一下）
------------------------------------------------
1. 桌面点「Index翻译桥」图标。
2. 首次会询问通知权限，请选「允许」（要显示端口号）。
3. 界面显示：● 运行中 · 端口 8080
4. 点「复制地址」，得到：http://127.0.0.1:8080/v1

端口 8080 被别的应用占用时，会自动换成 8081、8082……
以界面上显示的数字为准，不要照抄本文档里的 8080。

代理在"前台服务"里运行，切到后台、息屏都不影响。


三、语音翻译（不用切浏览器，直接在 App 里说）
------------------------------------------------
1. 主界面往下滑，在「语音翻译（外语 → 中文）」那一块。
2. 第一次按住大按钮「按住说话」时，会弹麦克风权限，选「允许」。
3. 按住不放，对着麦克风说一句外语；「原文」栏会实时显示识别中的文字。
4. 松手即停止录音，稍等一下，「译文」栏出现简体中文结果。
5. 点「复制译文」就能粘到微信 / 笔记 / 任何地方。

识别语言默认是英语，面板里可以切成日语、韩语或跟随系统。
目标语言固定是简体中文（这一版不做多目标语言选择）。

注意：
- 语音识别用的是你手机自带的语音服务（Google / 厂商实现），有的机型要联网、
  要先把系统里的「语音输入」启用才能用；如果按钮是灰的，说明系统里没有可用识别服务。
- 翻译优先走本机代理，代理没开也能用（直连上游）。
- 说清楚一点、离麦克风近一点；识别不到会提示「没听清，再说一次」。


四、在沉浸式翻译里填什么
------------------------------------------------
翻译服务：OpenAI 兼容 / 自定义 OpenAI
接口地址：http://127.0.0.1:端口/v1      ← 结尾必须是 /v1
模    型：Index-Translate-9B
API Key ：index（随便填，上游不校验）

其它可选模型：
  Index-Translate-9B        默认，速度/质量平衡
  Index-Translate-2B        更快，适合长文批量
  Index-Translate-35B-A3B   旗舰，复杂句子/版式


五、国产系统必做的"保活"设置（否则锁屏后代理会断）
------------------------------------------------
荣耀 / 华为：
  设置 → 应用 → 应用启动管理 → 找到「Index翻译桥」→ 关闭"自动管理"
  → 打开"允许自启动""允许关联启动""允许后台活动"
  再：设置 → 电池 → 更多电池设置 → 关闭"休眠时始终保持网络连接"的省电限制

小米 / Redmi：
  设置 → 应用设置 → 应用管理 → Index翻译桥 → 省电策略 → 无限制
  安全中心 → 授权管理 → 自启动 → 允许

OPPO / vivo / 一加：
  设置 → 电池 → 后台耗电管理 → 允许后台运行
  设置 → 应用管理 → 自启动 → 允许

通用：通知栏出现"代理运行中"的常驻通知就说明服务活着。


六、常见问题
------------------------------------------------
Q: 扩展报 ERR_CONNECTION_REFUSED / 连接被拒绝
A: 代理没在跑，或端口变了。打开 App 看当前端口，重新填一遍地址。

Q: 扩展报 404
A: 地址漏了 /v1，或你填到了 /v1/chat/completions。只填到 /v1 为止。

Q: 返回 400 未知模型
A: 模型名拼错，用上面列出的名字。

Q: 译文里夹着思考过程
A: 你在扩展里自定义了 chat_template_kwargs，删掉它，让代理自动注入。

Q: 点「自检」显示 HTTP 200，但翻译还是不通
A: 说明代理通、上游通，问题在扩展的填法（服务类型要选"OpenAI 兼容"）。

Q: 第一次翻译很慢
A: 9B 模型冷启动，正常。换 Index-Translate-2B 会快很多。

Q: 会很费流量吗？
A: 比扩展直连更省。非流式翻译的回复会压缩传输（实测可省九成以上），
   并且代理会复用与上游的连接，不再每条请求都重新握手。
   注意：上游目前不接受压缩后的请求体，代理首次会多试探一次再自动回退，
   不影响译文，也不影响后面每次的流量节约。

Q: 按住「说话」没反应 / 一直提示没听清
A: 先看主界面语音区的提示文字：
   - 「需要麦克风权限」→ 重新按一次并在弹窗里允许；已拒绝就去
     系统设置 → 应用 → Index翻译桥 → 权限 → 麦克风 → 允许
   - 「本机没有可用的语音识别服务」→ 去系统设置里启用「语音输入 / Google 语音服务」
   - 「没听清」→ 按住时就开始说，说完再松手，不要把按钮当点击用

Q: 语音识别能用，但翻译一直失败
A: 面板会显示具体原因（HTTP 状态码或超时）。常见情况是网络不稳，
   或者上游限流；稍等几秒再按住重试。

Q: 电脑上的浏览器能不能用这个手机的代理？
A: 不能。本工具只监听 127.0.0.1，只在同一台手机上生效（这是刻意的安全设计）。

Q: 需要填 API Key / 要花钱吗？
A: 不需要。使用的是 bilibili 公开的免费接口，公共资源请勿滥用。


七、隐私
------------------------------------------------
- 不收集任何数据，无统计、无广告、无账号。
- 唯一网络行为：把你的翻译文本发给你请求的上游接口
  （index-translate.bilibili.com），与直接在浏览器里调用相同。
- 语音翻译：麦克风只在「按住说话」期间录音，录音交给系统自带的语音识别服务
  转成文字，本 App 不保存录音；后续只把识别出的文字发给上游接口。不按就不录。
- 只监听本机回环地址 127.0.0.1，局域网内其它设备无法访问。


八、卸载
------------------------------------------------
通知栏点「停止代理」→ 再到系统设置里卸载即可。
